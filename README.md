# Shadow Corporations

**Dominio:** [shadowcorp.pro](https://shadowcorp.pro)

Juego multiplayer de estrategia corporativa. Poder, traición y control en un mundo distópico.

## Stack

- **Frontend + Backend**: Next.js 14 (App Router)
- **Estilos**: Tailwind CSS
- **Base de datos / Auth**: Supabase (próximamente)
- **Hosting**: Render (un solo Web Service)

## Desarrollo local

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000)

## Estructura

```
src/
  app/           → Páginas y API routes
  components/    → Componentes reutilizables
  lib/           → Utilidades y tipos
  types/         → TypeScript types del juego
```
